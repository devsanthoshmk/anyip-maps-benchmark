What this run can’t tell us

One completed run covered 100 sessions and 100 queries in about 9 minutes 18 seconds. Small samples limit precision and do not establish a country effect. The overall success interval uses the Wilson score method.

  • No session lifetime. The run observed one exit IP in 87% of witnessed sessions but did not measure exit-IP TTL or first-block timing in a dedicated cohort.
  • No pool or load comparison. Only residential proxies were measured. The run does not establish concurrency capacity or how mobile, mixed, or local traffic would compare.
  • Witnesses have limits. IPv4 and IPv6 witness probes add about 2 KB per query, and a witness observation cannot confirm what IP the destination saw.
  • Challenge handling is limited. The HTTP client cannot solve dynamic reCAPTCHA challenges.
